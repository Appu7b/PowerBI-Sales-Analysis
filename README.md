# PowerBI-Sales-Analysis
Interactive Sales analysis Dashboard built using PowerBI to analyze sales performance,profitability, and business trends.

Dashboard Features
* Total Sales and Total Profit KPI Cards
* Sales analysis by region,segment, and category
* yearly sales trend visualization
* interactive Ordder Date and Region slicers
* Dark-themed dashboard design

Tools Used
* Microsoft PowerBI
* Data visualization
* Interactive reporting

Project file
download
Sales_Analysis_Dashboard.pbix
from this repository and open it using Power BI desktop
